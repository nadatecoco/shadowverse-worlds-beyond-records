# シャドバ戦績研究

iOS 26以降。SwiftUI・SwiftData・App Intents・ActivityKit・WidgetKitによるローカル戦績研究アプリです。

「シャドバ戦績研究.xcodeproj」のShadowRecordスキームを実行します。実機用には既存の開発チームで署名してください。

## ⚡ 高速入力で戦績を記録

本体の「⚡ 高速入力を試す」をタップすると、実際の入力と保存をアプリ内で確認できます。Action Buttonから起動した場合は、本体へ移動せず、iOSのInteractive Snippetへ同じ項目を表示します。通常アプリ内からシステムのSnippetを強制表示する公開APIはありません。

デッキや環境を先に登録する必要はありません。初回から自分側の7クラスを選べます。

1. iPhoneの設定 → アクションボタン → ショートカット → ショートカットを選択 → **アプリ欄の「シャドバ戦績研究」→「戦績を記録」**を選びます。Shortcutsアプリで自作する必要はありません。
2. iPhone左側、音量ボタンより上の物理Action Buttonを長押しします。右側のカメラコントロールとは別です。
3. 小さい画面で自分の候補と相手クラスを選びます。相手のアーキタイプ登録がある場合は任意で選べます。
4. 「先攻勝ち／後攻勝ち／先攻負け／後攻負け」を選び、「保存」を押します。

保存した試合は、日時、自分の候補、相手クラス、相手アーキタイプ、勝敗、先後を持つ通常の戦績として履歴へすぐ反映されます。同じ入力画面で保存を連打しても、1試合だけ記録します。

「デッキ／設定」→「自分の候補を追加・編集」では、標準7クラスに「エルフ（ダストデイズエルフ）」「エルフ（リノセウスエルフ）」のような候補を追加できます。名前とクラスを指定するだけで、高速入力の自分側候補と相手アーキタイプ候補へ反映されます。

## ライブ戦績

本体上部で「ライブ戦績を開始」を押すと、現在環境・現在使用中デッキの集計を表示します。終了は「ライブ戦績を終了」。勝敗、勝率、デッキ名、連勝数を表示し、狭いDynamic Islandでは勝敗だけに絞ります。戦績の追加・修正・削除・取り消し、使用デッキ・環境の変更で更新します。

Live ActivityはOSが表示位置と期間を管理し、通常最長8時間です。独自overlayではなく、ゲーム左上へ固定することはできません。横画面・ロック状態での見え方は端末とOSによります。表示が終了していても戦績は保存できます。インターネットやプッシュ通知は使いません。

## Control Centerとその他の入口

右上から下へスワイプ → 空いた場所を長押し → コントロールを追加 → このアプリの「戦績入力」。ホームボタン搭載端末では下端から上へスワイプします。本体の高速入力画面が直接開き、相手情報も入力できます。ロック画面・Action Buttonのコントロールにも配置できます。

Action ButtonがないiPhoneはControl Centerを推奨します。背面タップは保存済みショートカットを割り当てる仕組みで、内蔵操作の直接選択は実機未確認です。

## Apple APIと保存の制約

- iOS 26以降。Snippetの表示と閉じる操作、Dynamic Islandの位置や優先度はOSが管理します。ゲームの一時停止や画面復帰はゲーム側の挙動にも依存します。
- Control CenterからはSnippetを表示せず、本体を開きます。
- Action Button専用設定へ飛ぶ公開APIは使用できないため、設定手順を案内します。アクセス許可画面へ送るボタンはありません。
- バックグラウンド実行のApp Intentが本体と同じSwiftDataへ保存します。Widget側はActivityのContentStateを描画するだけで、DBの二重管理やApp Groupへの移動は行いません。
- 初回に旧形式を移行し、変更前のJSONをDocumentsの「移行前バックアップ」に保存します。移行に失敗した場合は初期化せずエラーを表示します。旧JSONも読み込めます。新版のJSONは旧版アプリへ戻せません。
- ロック中は端末認証が必要になる場合があります。使用デッキが削除・アーカイブされた場合は本体で選び直してください。
